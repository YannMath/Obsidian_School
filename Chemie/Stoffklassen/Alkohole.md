<h2>Aufbau</h2>

Alkohole bestehen aus einer langen Kette an *Kohlenstoffatomen* $C$ und *Wasserstoffatomen* $H$ und mindestens einer *Hydroxylgruppe* $OH$.

Die allgemeine Formel für Alkohole lautet daher auch $C_nH_{2n + 1}OH$.

Bsp. *Ethanol*:
$CH_3CH_2OH$

```smiles
CCO
```

---
<h2>Arten von Alkoholen</h2>

Man kann Alkohole aufgrund ihrer Anzahl an $OH$ Gruppen unterscheiden:

<h4>Einwertige Alkohole</h4>

Diese besitzen *eine* $OH$ Gruppe, z.B. *Ethanol*:
```smiles
CCO
```

<h4>Zweiwertige Alkohole</h4>

Diese besitzen *zwei* $OH$ Gruppen, z.B. *Ethandiol*:
```smiles
C(CO)O
```

<h4>Dreiwertige Alkohole</h4>

Diese besitzen *drei* $OH$ Gruppen, z.B. *Glycerin*:
```smiles
C(CO)(CO)O
```

---
<h2>Eigenschaften von Alkoholen</h2>

Aufgrund der *funktionellen Gruppe* $OH$ von Alkoholen haben diese eine Reihe an Eigenschaften:
> - Sie sind *polar*
> - Sie können *Wasserstoffbrücken bilden*
> - Sie haben *hohe Siedepunkte*
> - Sie sind *wasserlöslich*
